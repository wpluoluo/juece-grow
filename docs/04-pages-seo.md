# juece-grow · 页面清单与 SEO 落地

## 1. 站点类型与页面清单

每个项目下可建一个或多个站点。站点模板决定页面结构。

| 站点模板 | 页面 | 说明 |
|---|---|---|
| 营销站 | 首页 hero/产品矩阵/行业方案/案例/CTA | 可被搜索的主站 |
| 官网 | 首页/关于/服务/联系 | 品牌与留存 |
| 落地页 | 单 CTA 页 | 针对单渠道投放 |
| 内容站 | 文章列表/文章详情 | SEO 长尾 |

公开站点页面清单（模板化，后台可配）：
```
站点:
├─ 首页
├─ 功能 / 产品
├─ 行业方案
├─ 案例
├─ 文章列表
├─ 文章详情
├─ 落地页(可选, 按渠道)
└─ 页脚/导航
```

## 2. 后台管理与"改文案"能力

- 页面区块化(Block)：运营在后台可编辑每个区块的标题、描述、按钮文案，改完发布即生效。
- 文章管理：Payload Lexical 富文本发文，可配标题、摘要、封面。
- 站点设置：站点名、logo、导航、SEO 默认。
- 权限：editor 可改内容但不可发布，admin 可发布。

## 3. SEO 落地清单

| 项 | 做法 |
|---|---|
| 元信息 | 每页可配 title / description / keywords |
| Open Graph | og:title / og:image / og:url，利于分享 |
| 结构化数据 | 文章用 Article schema，落地页可选 |
| 站点地图 | sitemap.xml 自动生成，提交搜索引擎 |
| 静态预渲染 | SSG 生成 HTML，搜索引擎可抓 |
| 文章页 | 随站点 SSG 构建生成，发布后触发重新构建即可收录 |
| 规范链接 | canonical 防重复收录 |
| robots.txt | 控制抓取范围 |
| 页面速度 | SSG（Astro 静态产物），Core Web Vitals 达标 |

## 4. 发布即 SEO

- 文章「发布」后触发站点重新构建，再生成对应文章 URL。
- 站点配置提交后，可一键导出/提示提交 sitemap。
- 每个项目 slug/子域独立，避免站点互相抢关键词。
