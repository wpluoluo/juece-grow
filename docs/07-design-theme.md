# 07 · 后台视觉主题：克制现代编辑部

> 本文档是后台（apps/cms）视觉体系的设计真值。实现落在 `apps/cms/src/app/(payload)/custom.scss`。
> 原则遵循 AGENTS.md / CLAUDE.md：纯 CSS 覆盖，不改 schema / 数据 / 路由 / 依赖；不引入兜底与双写；自研文件 ≤1000 行。

## 1. 设计方向

后台给运营与内容同学长期使用，气质定为「克制现代编辑部」：

- **编辑部**：像一本排版考究的刊物，信息有序、层级清楚、批量条目可快速扫读。
- **克制**：一个主强调色、暖中性底、统一圆角、克制的留白与分隔线，不堆动效。
- **现代**：继承公开站品牌「觉策青」与冷石墨中性，深浅两态一致，数字读取友好。

一句话：**有人味、可长时间看、扫读高效，不抢内容戏份。**

## 2. 设计令牌

### 2.1 品牌色（继承公众站，回溯 `reference/juecesass-marketing-20260825`）

| 令牌 | 色值 | 用途 |
| ----- | ------- | ----- |
| 品牌青 primary | `#2f8f96` | 主按钮、激活态、链接、选中、左指示条 |
| 品牌青 hover | `#257a80` | 主按钮 hover |
| 品牌青 active | `#1b5f65` | 主按钮 active / 按压 |
| 品牌青淡底色 | `rgba(47,143,150,.08)` | 分组标题底、当前项底、图表主色 |

### 2.2 中性色（冷暖靠近品牌、近墨但不上纯黑）

| 令牌 | 用途 |
| ----- | ----- |
| `--theme-elevation-800` ~ `#1c2b2e` | 主文本（带品牌青沉淀的深墨） |
| `--theme-elevation-600` ~ `#3f5054` | 次级文本 |
| `--theme-elevation-400` ~ `#7c8b8e` | 弱化文本 / 辅助说明 |
| `--theme-elevation-200` ~ `#ccd6d6` | 分隔线 / 边框 |
| `--theme-elevation-100` ~ `#e6ecec` | 分组底 / hover 底 |
| `--theme-elevation-50` ~ `#f2f6f6` | 卡片底 / 行底 |
| `--theme-elevation-0` ~ `#ffffff` | 页面主体底 |

### 2.3 状态语义（对接线索阶段，延续现有 4 阶段）

| 阶段 | 底 | 字 | 用途 |
| ----- | ----- | ----- | ----- |
| new 新线索 | `#e0f2f1` | `#1f6f75` | 青（待跟进） |
| contacted 跟进中 | `#fbf0dd` | `#9a6b1f` | 琥珀（进行中） |
| converted 已成交 | `#e2f2e6` | `#2e7d4f` | 绿（成交） |
| closed 已关闭 | `#eef1f1` | `#6b787b` | 灰（关闭） |

### 2.4 圆角（统一克制，不漂移）

| 令牌 | 值 | 用途 |
| ----- | ----- | ----- |
| `--style-radius-s` | `6px` | 小控件 / 徽章内 |
| `--style-radius-m` | `8px` | 输入框 / 按钮 / 导航项 |
| `--style-radius-l` | `12px` | 卡片 / 模块 / 面板 |

### 2.5 字号与行高（正文 ≥16px，长文舒适）

| 层级 | 字号 | 字重 | 用途 |
| ----- | ---- | ---- | ----- |
| 页面标题 | `1.5rem` | 700 | 工作台顶栏标题 |
| 区块标题 | `1.05rem` | 650 | 卡片分区标题 |
| 行标题 | `0.95rem` / 600 | 600 | 列表条目主行 |
| 正文 | `0.9rem` / normal | — | 列表正文 / 表单 |
| 辅助 | `0.78rem` / normal | — | 元信息 / 时间 / 说明 |

数字统一 `font-variant-numeric: tabular-nums`，避免读取跳动。

### 2.6 阴影（向青灰染色，不用纯黑）

| 令牌 | 值 | 用途 |
| ----- | ----- | ----- |
| hover | `0 6px 20px -8px rgba(18,34,40,.14)` | 卡片/行 hover 抬升 |
| 浮层 | `0 12px 40px -12px rgba(18,34,40,.18)` | 抽屉 / 弹层 |

## 3. 骨架与分层（编辑部式的版面网格）

- **侧边导航**：暖白精细面板底 `#ffffff`，右侧 1px 细边框与内容区分野；分组间距舒展，激活项品牌青「左指示条 + 淡青底」，导航字采用品牌沉淀深墨 `#1c2b2e`。*（经 Native DOM 实测，Payload 内置导航文字/图标色不随容器底色自动切换，深墨底会破坏可读性，故采用暖白面板以保证稳定可读。）*
- **内容区**：暖白底 `#f7f9f9`；页面主体卡片为纯白底、细边框、圆角 `--style-radius-l`。
- **横向分隔**：用 1px `--theme-elevation-100` 而非重阴影，制造编辑部常见的细线分割。

## 4. 组件样式

### 4.1 导航（nav）
- 导航容器：暖白面板底，右侧 1px 细边框；分组名与链接之间留白舒展。
- 导航链接：圆角 `--style-radius-m`、hover 提亮、激活项淡青底 + 左 3px 品牌青指示条，文字加粗。
- 「运营工作台」入口：置顶、品牌青图标、加粗，激活同色。
- 分组名：小字号、次级色、两端与分隔线留白。

### 4.2 工作台（Dashboard）
- 顶栏：品牌标题 + 日期说明 + 右侧主按钮「查看全部线索」。
- 指标卡：白底细边框圆角，图标 36px 圆角块 + 品牌青，数值大号；hover 轻微上浮。
- 图表卡：白底细边框；纯 SVG 实现，无第三方图表库；尊重 `prefers-reduced-motion`。
- 空状态：居中弱化，虚线边框引导。

### 4.3 列表 / 表格
- 行 hover 淡底，整行可点跳转。
- 状态徽章：圆角胶囊、语义色、`tabular-nums`。
- 表头：次级色、小字号、贴近但不挤。

### 4.4 按钮
- 主按钮：品牌青实底 + 白字 + hover 加深 + `translateY(-1px)`。
- 次按钮：白底细边框；hover 提亮。

### 4.5 表单 / 编辑器
- 输入框：细边框、focus 品牌青描边、圆角 `--style-radius-m`。
- 富文本：正文行高 `1.7`，标题分级清晰。

## 5. 动效（克制、尊重减少动效偏好）

- 统一 `160–200ms ease` 过渡，只用于 hover / 激活 / 轻微抬升。
- 图表数值入场：一次 0.5s 上移淡入，不循环。
- 全局遵守：在 `prefers-reduced-motion: reduce` 下将动画与过渡时长压到 ~0。

## 6. 边界与自检

- 纯 CSS（在 `custom.scss` 内，`@layer payload-default`），不改 schema / 数据 / 路由 / 依赖。
- 不引入外部字体、图标库、图表库；图标用内联 SVG。
- 不出现兜底 / 双写 / 兼容写法；CSS 变量单一来源。
- 中英双语文案维持现状（Payload i18n + middleware zh-CN 默认）。
- 自研文件保持 ≤1000 行。
- 变更后跑 `pnpm build`（CMS）确认样式编译无错，并在浏览器核对导航 / 工作台 / 列表 / 表单。
