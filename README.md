# juece-grow · 觉策增长

开源独立项目：统一管理你名下多个产品的获客官网、文章、留资、线索与渠道归因。

## 定位
一个自己的获客营销平台，替你把每个产品的官网、文章、留资入口、线索跟进在一个平台统一管起来。

## 技术栈
- Nuxt 4.5.x / Vite 8（前端与服务端合一，SSG/ISR 利于 SEO）
- MySQL 8 + Prisma 7（建模站点/内容/线索）
- TipTap（富文本）
- Chatwoot（客服收件箱，线索主数据在自己 MySQL）
- 认证：自有 Nuxt 服务端
